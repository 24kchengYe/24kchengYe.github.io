注意力机制，按设计拆开看

MHA、MLA、稀疏注意力和线性注意力，分别在改变什么？把十八个常见概念放到六个设计问题里：共享、压缩、可见性、选择、状态，以及执行。

2026 年 10 月 · 图解笔记

注意力用查询 Q 与键 K 计算相关性，再加权读取值 V。改动 Q、K、V 的组织方式、允许读取的范围或计算过程，会得到不同的优化路线；它们常常可以组合。

起点：缩放点积注意力

Attention(Q, K, V) = Softmax(QKᵀ / √d + M)V

M 是掩码：允许访问的位置为 0，禁止的位置为负无穷。Softmax 沿键的位置归一化。下文的“头”指并行注意力子空间，“条目”指缓存中的历史表示。

共享多少组 KV

MHA 为每个查询头配一组独立的 K、V。MQA 让所有查询头共享一组 KV。GQA 位于两者之间：查询头分组，同组共享 KV，各组相互独立。三者都可以保留多个查询头；GQA 的每个查询头只读取所属组的 KV，最后拼接各头的输出。

在头维度和精度相同时，32 个查询头采用 8 个 KV 头，KV 张量存储量是 32 个 KV 头的四分之一；采用 1 个则是三十二分之一。历史长度没有缩短，稠密注意力的位置交互仍随序列长度呈平方增长。缓存缩减比例也不等于端到端加速比。

KV 张量的存储量

KV bytes ≈ 2 × L × B × N × hₖᵥ × d × b

L 为层数，B 为批大小，N 为历史长度，hₖᵥ 为 KV 头数，d 为每头维度，b 为每元素字节数。这里假设 K、V 维度相同，未计入分页、元数据或副本。

Transformer · MQA · GQA

压缩维度，还是压缩条目

MLA 压缩每个 token 的 KV 内容特征。在 DeepSeek-V2 中，缓存保留低维潜向量 cᴷⱽ 和分离的 RoPE 位置键 kᴿ；历史 token 仍逐个保留。恢复 K、V 的投影可以在推理时吸收到其他权重中，无需每次显式重建完整 KV。

CSA 沿序列压缩历史条目。DeepSeek-V4 中，压缩 KV 和压缩索引键分别构造；主查询 Q 与索引查询 Qᴵ 从共享查询潜向量分别投影。索引器选择 Top-k，主注意力读取选中压缩 KV 与局部原始 KV。

HCA 使用更高压缩率，读取查询之前已完成的全部压缩块，并保留局部原始 KV。它没有查询相关的 Top-k 选择。CSA 与 HCA 压缩的是序列条目数，而非 MLA 的逐 token 内容特征。

DeepSeek-V2 · MLA · DeepSeek-V4 · CSA / HCA

允许访问哪些位置

完整因果注意力可以读取当前位置及所有过去位置。滑动窗口注意力（SWA）只保留最近 w 个直接可见位置。叠加多层后，信息可以间接传播得更远，但单层查询仍不能直接检索所有历史。

局部 + 全局注意力为少量 token 赋予全局连接。图中的 Longformer 式设计是双向的：普通位置读取邻域和全局位置，全局位置读取所有位置。用于自回归生成时，还需要单独设计因果约束。

窗口与位置交互量

SWA: max(0, t − w + 1) ≤ s ≤ t
Full: O(N²)　·　SWA: O(Nw)　·　Local + global: O(Nw + Ng)

窗口 w 包含当前位置；g 为全局 token 数。这里固定头数和特征维度，只统计注意力的位置交互，不包含投影、FFN 或内存访问开销。

Mistral 7B · Longformer

由内容选择历史

NSA 将压缩注意力、选块后的原始注意力、滑动窗口注意力分成三路。三路共享查询 Q，但分别投影 KV，并在各自归一化后门控融合。选块时，先把压缩注意力分数映射到选择块，再对同一 GQA 组内的 query heads 求和，选择 Top-n 块。用于选块的是分数 P，不是压缩分支的输出向量 o。

DSA 将索引与主注意力分开。DeepSeek-V3.2 的 Lightning Indexer 对历史 token 打分，选择 Top-k 后，主 MLA 才读取对应 KV。索引查询与主查询承担不同职责；索引分数也不是最终注意力权重。

MoBA 按历史块的平均 K 选择块。当前块始终保留，并在块内使用因果掩码；原论文的 k 已包含当前块，因此 k = 3 表示最多两个历史块加当前块。选中 token 的注意力统一归一化，不能把各块结果简单平均。

稀疏读取减少主注意力实际处理的条目，索引和选块仍有成本。某一步没有选中的历史，后续仍可能用到；Top-k 读取本身不意味着可以删除其余 KV 缓存。

用状态承载历史

线性注意力把历史写入固定形状的状态，再用查询读取。核线性注意力通过特征映射 φ 改变相似度核，可以递推累加外积；它通常不等于对原始 Softmax 注意力做精确的乘法重排。

Gated DeltaNet 先用每头标量门 α 衰减旧状态，再计算当前值 v 与状态预测值 S̄k 的残差，用 β 控制残差外积的写入强度。更新后的状态由 q 读取，随后进入归一化和输出门。

KDA 保留预测残差与 delta 写入，把遗忘门 α 细化到 key 的各个通道。不同通道可以有不同的遗忘率；改变的是旧状态如何衰减，而非取消残差更新。

三种状态更新

采用列向量，状态 S 的行对应 value，列对应 key 或其特征。下式只保留核心递推，门、键和查询视为已按各方法完成预处理。

Kernel linear attention

Sₜ = Sₜ₋₁ + vₜ φ(kₜ)ᵀ
zₜ = zₜ₋₁ + φ(kₜ)
oₜ = Sₜ φ(qₜ) / (zₜᵀ φ(qₜ))

Gated DeltaNet

S̄ₜ = αₜ Sₜ₋₁
Sₜ = S̄ₜ + βₜ (vₜ − S̄ₜ kₜ) kₜᵀ
oₜ = Sₜ qₜ

KDA

S̄ₜ = Sₜ₋₁ Diag(αₜ)
Sₜ = S̄ₜ + βₜ (vₜ − S̄ₜ kₜ) kₜᵀ
oₜ = Sₜ qₜ

核线性注意力的分母需数值稳定处理。Gated DeltaNet 的 α 是每头标量，KDA 的 α 是 key 通道向量；β 控制 delta 写入强度。

固定形状描述的是固定维度下单个递推层的状态，不代表任意长历史都能无损保存，也不代表整个混合模型的内存恒定。Kimi Linear 每三层 KDA 搭配一层完整 MLA，用全注意力层补充检索能力。

Linear Transformer · Gated DeltaNet · Kimi Linear · KDA

信息来源与执行方式

Self-attention 的 Q、K、V 来自同一序列；cross-attention 的 Q 来自一侧，K、V 来自另一侧。它们描述信息从哪里来，可与不同的共享方式和掩码组合。Self-attention 本身没有规定必须因果或必须双向。

FlashAttention 优化的是执行：将 Q、K、V 分块放入片上存储，通过在线 Softmax 合并结果，避免在显存中物化完整的 N × N 分数矩阵。它保留精确注意力的数学结果，允许浮点舍入差异；稠密注意力的算术量仍是平方级。

Transformer · FlashAttention

读架构时，沿着数据走

先看一个 token 被存成什么，再看查询能读哪些位置、由谁选中，最后看结果怎样归一化和执行。Mistral 7B 的 GQA + SWA 同时减少 KV 头数和直接可见范围；Kimi Linear 的 KDA + MLA 则在状态记忆与显式历史之间分配层。沿着这些路径，名字相近的方法也能分清，互补的设计也更容易组合。
