Nimble 9B / KEV 0.8B

用软标签训练路由模型Training Routing Models with Soft Labelsソフトラベルでルーティングモデルを訓練する

一个路由模型既要选对入口，也要给出有用的概率。我们在 Nimble 与 KEV 上比较硬标签监督、概率蒸馏和强化学习：在相应的同数据对照中，保留完整参考概率的直接监督取得了更好的类别一致率与分布拟合。A router needs to choose the right destination and return useful probabilities. We compared hard-label supervision, probability distillation, and reinforcement learning on Nimble and KEV. In their respective matched-data comparisons, direct supervision on the full reference distribution improved both class agreement and distribution fit.ルーターには、適切な振り分け先と有用な確率の両方が求められる。NimbleとKEVで、ハードラベルによる教師あり学習、確率蒸留、強化学習を比較した。それぞれの同一データ上の比較では、参照確率分布全体を直接学習する方法が、クラス一致率と分布への適合度で優れた結果を示した。

任务是把用户需求分到电子表格（Sheet）、多维表格（Base）或其他／无法区分（Others），返回三类概率。上层可以据此选择入口，并识别需要进一步澄清的请求。The task assigns user requests to a spreadsheet (Sheet), a multidimensional table application (Base), or other/ambiguous requests (Others), returning probabilities for all three. The caller can use them to choose an entry point and identify requests that need clarification.ユーザーの要求を、スプレッドシート（Sheet）、多次元テーブルアプリケーション（Base）、その他・判別困難（Others）に振り分け、3クラスの確率を返す。呼び出し側は、それを入口の選択や追加確認が必要な要求の識別に利用できる。

两种模型，两个评分头Two models, two scoring heads2つのモデル、2つのスコアリングヘッド

Nimble 使用 Qwen3.5-9B 与已有 LoRA，在答案起始位置读取 A/B/C 三个候选 token 的分数。KEV 使用 Qwen3.5-0.8B-Base、已有 LoRA 和选择头：将决定位置与各选项的隐藏表示分别投影到 256 维，再通过点积给选项打分。两者都对候选分数做 Softmax，直接返回概率。Nimble combines Qwen3.5-9B with its existing LoRA and reads the scores of candidate tokens A/B/C at the answer position. KEV combines Qwen3.5-0.8B-Base with its existing LoRA and a pointer head: the decision and option representations are projected to 256 dimensions and scored by dot product. Both apply Softmax over candidate scores and return probabilities directly.NimbleはQwen3.5-9Bと既存のLoRAを用い、回答開始位置で候補トークンA/B/Cのスコアを読む。KEVはQwen3.5-0.8B-Base、既存のLoRA、選択ヘッドを使い、決定位置と各選択肢の隠れ表現を256次元に射影して内積で採点する。どちらも候補スコアにSoftmaxを適用し、確率を直接返す。

Nimble 冻结底座和词表头，只更新约 43.3M 个已有 LoRA 参数；KEV 冻结底座，更新约 11.3M 个 LoRA 与选择头参数。各方案从各自公开模型独立起训。Nimble freezes the backbone and vocabulary head, updating about 43.3M existing LoRA parameters. KEV freezes the backbone and updates about 11.3M LoRA and pointer-head parameters. Each treatment starts independently from its respective public model.Nimbleは基盤モデルと語彙ヘッドを凍結し、既存のLoRA約43.3Mパラメータを更新する。KEVは基盤モデルを凍結し、LoRAと選択ヘッドの約11.3Mパラメータを更新する。各条件は、それぞれの公開モデルから独立に学習を開始する。

Hard-label SFT minimizes cross-entropy for the target class; SFT + Brier adds squared probability error against a one-hot target. The two GRPO treatments use negative Brier or RLCR rewards. 把完整概率作为监督Supervising the full distribution確率分布全体を教師信号にする

后续训练由规则 Agent 提供三类参考概率 q。硬标签取 y = argmax(q)，只监督一个类别；软标签保留整个 q，最小化软交叉熵。类别和概率只参与损失，不进入模型输入。这些标签由 Agent 按规则生成，并非商业 Jev 的输出。Later training uses a rule-guided Agent to supply a three-class reference distribution q. Hard labels take y = argmax(q) and supervise one class; soft labels retain q and minimize soft cross-entropy. Labels and probabilities enter only the loss, not the model input. These targets were generated by an Agent following rules, not by the commercial Jev model.後続の学習では、ルールに従うAgentが3クラスの参照確率qを与える。ハードラベルはy = argmax(q)として1クラスを教師信号にし、ソフトラベルはq全体を保持してソフト交差エントロピーを最小化する。ラベルと確率は損失のみに使い、モデル入力には含めない。これらの目標はルールに従うAgentが生成したもので、商用Jevモデルの出力ではない。

KEV：直接蒸馏与软目标 GRPOKEV: direct distillation versus soft-target GRPOKEV：直接蒸留とソフト目標GRPO

KEV 的对照使用 3,000 条训练数据，三类各 1,000 条，独立训练 1 个 epoch。两组都保留 Agent 概率：直接蒸馏最小化软交叉熵，GRPO 用概率平方误差构造奖励。重排候选时同步重排目标概率，保留完整 query，不加入干扰选项。The KEV comparison uses 3,000 training items, 1,000 per class, with one epoch from independent initializations. Both treatments retain Agent probabilities: direct distillation minimizes soft cross-entropy; GRPO rewards low squared probability error. Candidate permutations also reorder target probabilities. Queries remain complete, with no distractor options added.KEVの比較は学習3,000件、各クラス1,000件を用い、独立に初期化して1エポック学習した。両条件ともAgent確率を保持する。直接蒸留はソフト交差エントロピーを最小化し、GRPOは確率二乗誤差から報酬を作る。候補を並べ替える際は目標確率も同期し、queryを省略せず、妨害選択肢を追加しない。

GRPO 在概率空间里探索GRPO explores probability space確率空間を探索するGRPO

这里的 GRPO 直接扰动三类 logits。每条 query 产生 8 个高斯扰动候选，经过 Softmax 得到概率，再计算奖励和组内相对优势。候选是概率向量，训练没有生成推理文本。This GRPO implementation perturbs the three class logits directly. Each query produces eight Gaussian-perturbed candidates, followed by Softmax, rewards, and group-relative advantages. Its candidates are probability vectors; training generates no reasoning text.このGRPO実装は3クラスのlogitsを直接摂動する。queryごとにガウス摂動を加えた候補を8つ生成し、Softmax、報酬、グループ内の相対アドバンテージを計算する。候補は確率ベクトルであり、学習時に推論テキストは生成しない。

Nimble 的约 39%–48% 探索组奖励几乎相同，这些组的策略优势被置零，稳定项仍可更新参数。KEV 软目标实验中的低方差组为 0/3,000，却仍低于直接蒸馏。相同的结果方向，不能套用同一种机制解释。About 39%–48% of Nimble's exploration groups had almost identical rewards. Their policy advantages were set to zero, while stabilizing terms could still update parameters. KEV's soft-target experiment had zero low-variance groups out of 3,000, yet still trailed direct distillation. The same outcome does not imply the same mechanism.Nimbleでは探索グループの約39%–48%で報酬がほぼ等しく、方策アドバンテージがゼロに設定された一方、安定化項はパラメータを更新できた。KEVのソフト目標実験では低分散グループが0/3,000だったが、直接蒸留を下回った。同じ結果の方向でも、同じ機序で説明できるとは限らない。

正温度保持类别排序，所以可以调整置信度，却不会修复分类错误。实际选型应分别看类别一致率、参考概率拟合和校准表现，并检查 Base 这类关键路由的精确率。A positive temperature preserves class ranking: it can adjust confidence but cannot fix a classification error. Model selection should examine class agreement, reference-distribution fit, and calibration separately, alongside precision for critical routes such as Base.正の温度はクラスの順位を保つため、信頼度は調整できても分類誤りは直せない。モデル選定では、クラス一致率、参照分布への適合、較正を分けて確認し、Baseのような重要ルートの適合率も見る必要がある。

这组实验保留了一个简单起点：有完整概率监督时，先训练直接蒸馏基线，再检验强化学习是否带来额外收益。模型选型结合相同请求上的质量与处理成本，概率是否可信则交给独立的校准检查。These experiments suggest a straightforward starting point: when full probability targets are available, train a direct-distillation baseline before testing the added value of reinforcement learning. Choose models using quality and processing cost on the same requests, and assess probability reliability through a separate calibration check.これらの実験から得られる出発点はシンプルだ。確率分布全体を教師信号にできるなら、まず直接蒸留の基準モデルを学習し、強化学習による追加利得を検証する。モデル選定では同じ要求上の品質と処理コストを比較し、確率の信頼性は別の較正評価で確かめる。
