# Yecheng Zhang's Academic Homepage

Based on [AcadHomepage](https://github.com/RayeRen/acad-homepage.github.io) template.

## Local Development

```bash
bundle install
bundle exec jekyll serve
```

Visit http://localhost:4000

## Branch Structure

- `main` / `simple-academic` — Current simple academic homepage
- Tag `homepagev7-rich` — Previous rich JavaScript-based version
