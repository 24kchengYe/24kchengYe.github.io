Nimble 9B / KEV 0.8B

用软标签训练路由模型

一个路由模型既要选对入口，也要给出有用的概率。我们在 Nimble 与 KEV 上比较硬标签监督、概率蒸馏和强化学习：在相应的同数据对照中，保留完整参考概率的直接监督取得了更好的类别一致率与分布拟合。

2026 年 10 月 · 实验笔记

任务是把用户需求分到电子表格（Sheet）、多维表格（Base）或其他／无法区分（Others），返回三类概率。上层可以据此选择入口，并识别需要进一步澄清的请求。

两种模型，两个评分头

Nimble 使用 Qwen3.5-9B 与已有 LoRA，在答案起始位置读取 A/B/C 三个候选 token 的分数。KEV 使用 Qwen3.5-0.8B-Base、已有 LoRA 和选择头：将决定位置与各选项的隐藏表示分别投影到 256 维，再通过点积给选项打分。两者都对候选分数做 Softmax，直接返回概率。

Nimble 冻结底座和词表头，只更新约 43.3M 个已有 LoRA 参数；KEV 冻结底座，更新约 11.3M 个 LoRA 与选择头参数。各方案从各自公开模型独立起训。

内部高分与外部置信度

第一组 Nimble 实验使用 4,002 条合成／整理样本。硬标签 SFT 最小化正确类别的交叉熵；SFT + Brier 再加入对 one-hot 目标的概率平方误差。两种 GRPO 分别使用负 Brier 或 RLCR 奖励。所有方案用同一批 499 条内部回归样本和 20,000 条外部 query 评测。

GRPO 为三个种子的均值 ± 标准差；概率均未做温度缩放。内部集曾用于诊断；外部参考为来源分组代理标签。

在这组配置下，GRPO 的外部平均收益小于种子波动。数据的措辞、长度和类别比例都发生了变化，标签本身也影响读数：同一批 SFT 预测换用修订标签后，一致率从 65.02% 变为 78.26%。因此，外部收益与概率变化需要分别检查。

把完整概率作为监督

后续训练由规则 Agent 提供三类参考概率 q。硬标签取 y = argmax(q)，只监督一个类别；软标签保留整个 q，最小化软交叉熵。类别和概率只参与损失，不进入模型输入。这些标签由 Agent 按规则生成，并非商业 Jev 的输出。

Nimble：硬标签与软标签的同条件对照

两组使用相同初始化、4,200 条训练数据、2 个 epoch 和开发集选模流程。三类各 1,400 条，在同一批无训练重合的 3,000 条留出样本上比较。KL(q∥p) 衡量模型概率与 Agent 参考分布的差异，越低越好。

KEV：直接蒸馏与软目标 GRPO

KEV 的对照使用 3,000 条训练数据，三类各 1,000 条，独立训练 1 个 epoch。两组都保留 Agent 概率：直接蒸馏最小化软交叉熵，GRPO 用概率平方误差构造奖励。重排候选时同步重排目标概率，保留完整 query，不加入干扰选项。

直接蒸馏高出 5.25 个百分点，KL 也更低。完整概率可直接监督时，这组实验支持优先采用直接蒸馏。Nimble 与 KEV 的训练量、epoch 和模型结构不同，不能把两张表当作架构消融。

GRPO 在概率空间里探索

这里的 GRPO 直接扰动三类 logits。每条 query 产生 8 个高斯扰动候选，经过 Softmax 得到概率，再计算奖励和组内相对优势。候选是概率向量，训练没有生成推理文本。

GRPO 需要在同一请求的候选中分出好坏。Nimble 有约 39%–48% 的探索组奖励几乎一样，无法提供区分候选的更新信号，只有稳定项仍可更新参数。KEV 的软目标实验没有出现这类低方差组，却也落后于直接蒸馏；奖励分不开候选解释了前者的一项训练障碍，不能解释后者。

放到同一批外部请求上

最后，两版软标签模型共同处理 45,598 条 query，使用合并文件的参考标签。以下一致率以全部样本为分母，输入过长、没有返回分类结果的样本也计入；标签未经逐条人工确认，指标表示与参考类别的一致程度。

两组各并发 32、T = 1。耗时包含重试与超长输入处理，是整批处理时间。样本构成为 Sheet 5,886、Base 3,332、Others 36,380。

Nimble 的标签一致率更高，KEV 完成该批请求用时更少。两者对 Base 的精确率都偏低：被判为 Base 的请求中，参考也标为 Base 的比例仅为 42.41% 和 31.61%。这个分桶比总体分数更直接地指出了路由误报的改进方向。

排除与任一训练集精确重复的样本，并保留双方均有效的共同 44,259 条后，一致率仍为 84.99% 和 75.17%。这一检查保留了相同的排序，但没有排除语义近重复。

分清概率拟合与校准

软标签让模型更接近 Agent 分布；温度缩放则在训练结束后调整已有概率。对旧 Nimble SFT，用另外 3,308 条数据拟合 T ≈ 2.81，在 13,234 条重标验证样本上，ECE 从 16.14% 降到 1.59%，类别一致率保持 79.89%。ECE 比较置信度分桶中的平均概率与参考标签命中率。

p = Softmax(z / T)　·　T > 0

正温度保持类别排序，所以可以调整置信度，却不会修复分类错误。实际选型应分别看类别一致率、参考概率拟合和校准表现，并检查 Base 这类关键路由的精确率。

这组实验保留了一个简单起点：有完整概率监督时，先训练直接蒸馏基线，再检验强化学习是否带来额外收益。模型选型结合相同请求上的质量与处理成本，概率是否可信则交给独立的校准检查。
